# L4D2

Implementation: `modules/l4d2.nix`, `modules/l4d2-files.nix`, and
`resource/l4d2/`; host selection: `hosts/gz/configuration.nix` and `hosts/sz/configuration.nix`.

`l4d2-admins.age`, `l4d2-private.age`, and `l4d2-rcon.age` authorize the independent GZ and SZ agenix keys
alongside the PC management key; shared files also authorize their other consumers.
Read [secrets and identities](secrets.md) before changing passwords or recipients.

## SourceMod admins

GZ and SZ share `secrets/l4d2-admins.age`, containing SourceMod's
`admins_simple.ini` format. Edit on PC from the repository root:

```bash
AGENIX_RULES=secrets/agenix-rules.nix agenix -i /etc/ssh/agenix -e l4d2-admins.age
```

Add one SteamID per line, using the ID shown by `status` while connected:

```text
"STEAM_1:0:12345678" "99:z"
```

`z` grants all permissions; `99` is the immunity level. For limited admins,
choose flags from the [SourceMod admin documentation](https://wiki.alliedmods.net/Adding_Admins_%28SourceMod%29).
The initial encrypted template contains no admins; fill it before deployment,
including any existing admins you want to retain. `server-private.cfg` controls
display names and messages, not admin permissions.

Keep `l4d2-admins.age` in `gzFiles` in the ignored `secrets/agenix-rules.nix`;
`szFiles = gzFiles` also authorizes SZ, alongside the PC management key.
Check recipients and configurations, then deploy both hosts following the
[GZ/SZ deployment guide](gz.md):

```bash
AGENIX_RULES=secrets/agenix-rules.nix agenix -c
python3 scripts/test-l4d2.py
bash scripts/check-configs.sh gz sz
```

Changing the encrypted list triggers an L4D2 restart on deployment. At every
start, agenix's `l4d2`-owned, mode 0400 secret is installed as
`/home/l4d2/serverfiles/left4dead2/addons/sourcemod/configs/admins_simple.ini`
with mode 0600, after syncing the plugin package. Do not edit that runtime
copy: the next start replaces it. Verify the menu using `sm_admin` in the game
client. Disabling L4D2 removes the secret declaration, retaining encrypted
sources and persistent files.

## Plugin maintenance

Prefer `$GITHUB_DIR/l4d2-plugins` for plugin source, compilation, pinned addon
dependencies, and installation checks. Inspect that repository and its
`AGENTS.md` if present before editing. If `GITHUB_DIR` is unset, look for the
`l4d2-plugins` checkout alongside this repository. Keep server runtime settings,
services, accounts, and secrets in this Nix repository; avoid packaging overrides
that depend on the plugin package's internal build variables or directories.

Validate plugin changes with `nix flake check --option builders ''` there.
Once the plugin commit is available upstream, update only `l4d2-plugins` in both
`hosts/gz` and `hosts/sz`, then run `bash scripts/check-configs.sh gz sz`.
For unpublished local changes, use `--override-input l4d2-plugins
"path:$GITHUB_DIR/l4d2-plugins" --no-write-lock-file` during validation; do not
save a machine-specific path or an unpublished GitHub revision in either lock.

## Addon downloads

GZ's `antares.l4d2.fileServer.enable` enables `https://gz.chr.fan:8443/` while
L4D2 is enabled. nginx serves only top-level VPK/JPG files from the addons
directory through a read-only bind mount, with JPG previews and Basic Auth
username `l4d2`. Keep uploads readable (0644). TCP 8443 must also be allowed by
the cloud firewall. `l4d2-files-htpasswd.age` authorizes PC/GZ/SZ; the shared
`cloudflare-env.age` authorizes PC/HK/GZ/SZ. `modules/acme.nix` owns shared DNS
certificate issuance; neither port 80 nor 443 is needed on GZ.
Set the download password using
`nix shell nixpkgs#apacheHttpd nixpkgs#age -c bash scripts/set-l4d2-password.sh`,
then rebuild GZ. Validate using
`nix shell nixpkgs#nginx nixpkgs#apacheHttpd -c python3 scripts/test-l4d2-files.py`
and `bash scripts/check-configs.sh gz sz hk`.

## Host differences

`antares.l4d2.serverName`, `authorizedKeys`, and `fileServer.domain` select the
public name, game-account SSH keys, and download domain. Defaults preserve GZ.
SZ uses `Antares SZ L4D2`, its own `sz-l4d2` SSH key, and
`https://sz.chr.fan:8443/`. It shares plugins, game settings, private player
configuration, RCON credentials, and download credentials with GZ.
Both hosts use UDP 27015 and authenticated HTTPS on TCP 8443; allow these in
both the Nix firewall and the provider's security group.

The plugin package compiles `hp_tank_show` from its pinned
`L4D1_2-Plugins` source. It displays a green-to-red health indicator above a
damaged Tank; `tankhp_modified` still owns population-based health scaling.

During SZ deployment, A2S_INFO timed out on both hosts with the existing
`-nomaster` setup, while Source `qconnect` challenge requests succeeded.
Validate UDP 27015 using a connection challenge and RCON status; an A2S timeout
alone does not establish a firewall failure. Full player capacity still needs
eight real clients.

The addons ACL must explicitly set `m::r-x`: the preceding 0700 directory
rule resets the existing mask on repeated tmpfiles runs. Without an explicit
mask, nginx loses access after activation or reboot despite its named ACL.
